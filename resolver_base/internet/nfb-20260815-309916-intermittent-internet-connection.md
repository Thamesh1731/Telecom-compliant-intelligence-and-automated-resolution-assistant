# Technician-Approved Resolution

## Complaint

The router keeps restarting on its own, and I am unable to maintain a stable connection.

## User Feedback

Give better solution

## Correct Solution

Solution
Power cycle the router — unplug it from the power supply for 30–60 seconds, then reconnect it.
Check the power adapter and cable — make sure they are firmly connected and not damaged.
Try a different power outlet to rule out an unstable power source.
Check for overheating — place the router in an open, well-ventilated area and remove anything covering it.
Disconnect unnecessary devices temporarily and check whether the router still restarts.
Check the router firmware and update it if a newer version is available.
Reset network settings/configuration if the problem started after a configuration change.
If the router continues restarting after these steps, the power adapter or router hardware may be faulty. Contact your ISP or router manufacturer for a hardware check/replacement.
