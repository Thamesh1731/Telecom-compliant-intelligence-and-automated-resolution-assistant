# Technician-Approved Resolution

## Complaint

My wifi router is not working

## User Feedback

Give better solution

## Correct Solution

Restart the router — unplug it for 30 seconds, then plug it back in.
Check the power cable — make sure it's firmly connected.
Check the Internet/WAN light — if it's red or off, there may be an ISP connection issue.
Restart your device — phone/laptop and try connecting again.
Forget and reconnect to Wi-Fi — remove the network and enter the password again.
Move closer to the router — check whether the signal improves.
Try another device — see whether the problem affects all devices or just one.
Check the Ethernet/WAN cable — disconnect and reconnect it firmly.
Restart the ONT/modem if you have one separate from the router.
Factory-reset the router only as a last resort, because it can erase your ISP configuration.
