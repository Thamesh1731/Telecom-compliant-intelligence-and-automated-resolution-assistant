# CALL-04: Call Drops and Call Quality

## Category
Number & Calling Services

## Subcategory
Dropped Calls and Poor Call Quality

## Problem

The customer reports that voice calls are dropping, disconnecting
unexpectedly, or experiencing poor audio quality.

The problem may affect all calls, calls in specific locations, or calls
to specific destinations.

## Common Symptoms

- Calls disconnect unexpectedly
- Calls drop after a few seconds or minutes
- One-way audio
- No audio
- Distorted or robotic audio
- Voice cuts in and out
- Delayed audio
- Echo during calls
- Poor call quality in a specific location
- Calls drop when moving between locations
- Calls work intermittently
- Incoming calls have poor quality
- Outgoing calls have poor quality

## Possible Causes

- Weak cellular signal
- Network congestion
- Network coverage limitation
- Network handoff problem
- Device configuration issue
- SIM/eSIM provisioning problem
- Network outage
- Voice-service provisioning issue
- Partner-network issue while roaming
- Inter-carrier routing issue
- Device hardware or software problem
- Temporary network conditions

The AI must not assume the cause without sufficient evidence.

## Initial Diagnosis

Determine:

1. Whether calls are dropping or only experiencing poor audio quality.
2. Whether the problem affects incoming calls, outgoing calls, or both.
3. How frequently calls drop.
4. Whether the problem occurs in one location or multiple locations.
5. Whether the problem occurs indoors, outdoors, or both.
6. Whether the customer is stationary or moving when the call drops.
7. Whether mobile signal is weak when the issue occurs.
8. Whether SMS works normally.
9. Whether mobile data works normally.
10. Whether the issue occurs with all callers.
11. Whether the issue occurs with specific numbers.
12. Whether the customer recently changed devices.
13. Whether the customer recently changed SIM/eSIM.
14. Whether the customer is currently roaming.
15. Whether a known network or calling incident exists.

## Call Drop vs Call Quality Problem

### Dropped Call

The call disconnects unexpectedly.

Possible causes include:

- Coverage problem
- Network handoff
- Network congestion
- Network outage
- Device issue
- SIM/eSIM provisioning
- Routing problem

### Poor Audio Quality

The call remains connected but audio is degraded.

Possible causes include:

- Weak signal
- Network congestion
- Radio interference
- Device microphone or speaker issue
- Network-side voice-quality problem
- Partner-network issue

## Troubleshooting Procedure

### 1. Identify the Pattern

Determine whether the problem:

- Happens on every call.
- Happens occasionally.
- Happens at a specific location.
- Happens during movement.
- Happens only with certain callers.
- Happens only during specific times.

### 2. Check Cellular Signal

Determine whether the device has adequate cellular signal when the
problem occurs.

Signal indicators are only approximate and should not be treated as a
precise measurement of network quality.

### 3. Test Multiple Locations

If practical, determine whether calls work normally in another location.

If the problem occurs only in one location, investigate network
coverage or local network conditions.

### 4. Test Multiple Numbers

Determine whether calls to different numbers experience the same
problem.

If only one destination is affected, the issue may involve the
destination or routing path rather than the customer's device or line.

### 5. Test Incoming and Outgoing Calls

Determine whether:

- Incoming calls drop.
- Outgoing calls drop.
- Both are affected.

### 6. Check Device

Verify:

- Device software status
- Cellular settings
- Network selection
- Airplane mode status
- Physical damage when relevant

### 7. Check SIM/eSIM

Verify that the SIM/eSIM is:

- Detected
- Active
- Correctly provisioned
- Associated with the correct mobile line

### 8. Restart the Device

Restart the device and allow it to reconnect to the mobile network.

### 9. Check Provider Status

Check available information for:

- Voice outages
- Network incidents
- Coverage incidents
- Network maintenance
- Partner-network problems
- Routing incidents

## Diagnosis Guidance

### Calls Drop in One Location

Possible causes:

- Local coverage limitation
- Local network congestion
- Site-specific network issue
- Building penetration limitations

Do not automatically classify a location-specific issue as a
device failure.

### Calls Drop in Multiple Locations

Possible causes:

- Account or line provisioning
- SIM/eSIM issue
- Device issue
- Network-wide problem
- Voice-service issue

### Calls Drop While Moving

Possible causes:

- Network handoff problem
- Coverage transition
- Network congestion
- Device/network compatibility issue

### Calls Remain Connected but Audio Is Poor

Possible causes:

- Weak signal
- Network congestion
- Device microphone/speaker issue
- Network voice-quality issue

### Only One Caller Is Affected

Possible causes:

- Caller-side network problem
- Destination issue
- Inter-carrier routing problem

Do not automatically classify the customer's line as defective.

### Incoming Calls Have Poor Quality but Outgoing Calls Are Normal

Possible causes:

- Incoming routing path
- Caller-side network
- Network-specific issue
- Device/network interaction

### Outgoing Calls Have Poor Quality but Incoming Calls Are Normal

Possible causes:

- Outgoing routing
- Network conditions
- Device configuration
- Provider-side voice-service issue

### Problem Started After SIM/eSIM Replacement

Possible causes:

- Provisioning issue
- Incorrect line association
- Activation problem

Check the appropriate SIM/eSIM workflow.

### Problem Occurs While Roaming

Possible causes:

- Partner-network coverage
- Partner-network congestion
- Roaming voice compatibility
- Partner-network outage
- Roaming provisioning

Route to the appropriate roaming workflow.

## Resolution

The issue may be resolved by:

- Moving to an area with better coverage.
- Resolving a confirmed network incident.
- Correcting SIM/eSIM provisioning.
- Correcting supported device settings.
- Resolving a provider-side voice-service issue.
- Resolving a partner-network issue while roaming.

After resolution, verify:

- Incoming calls
- Outgoing calls
- Call stability
- Audio quality

## Escalation Conditions

Escalate when:

- Calls consistently drop despite adequate signal and standard
  troubleshooting.
- Poor call quality occurs across multiple locations.
- Account and line records indicate that calling should work normally.
- SIM/eSIM provisioning appears incorrect.
- Multiple customers report similar call-quality problems.
- A network outage or degradation is suspected.
- A routing issue is suspected.
- The problem persists after standard troubleshooting.
- Manual provider-side investigation is required.

## Potential Voice Quality Incident

Multiple similar complaints may indicate a broader network or voice
incident.

Example:

Ticket 8301
"Calls keep dropping in the same area."

Ticket 8302
"Everyone I call says my voice keeps cutting out."

Ticket 8303
"Calls are dropping repeatedly this afternoon."

Same service
+
Similar location or time
+
Similar symptoms
=
Potential Voice Quality Incident

The AI must not declare a confirmed incident without authoritative
provider confirmation.

## Human Agent Workflow

When a call-quality complaint is escalated:

1. Review the AI-generated summary.
2. Review the original customer complaint.
3. Verify customer identity through the authorized process.
4. Verify account and mobile-line status.
5. Review network registration.
6. Review reported locations.
7. Review call-drop pattern.
8. Check SIM/eSIM provisioning.
9. Check device information when relevant.
10. Check current network incidents.
11. Review related complaints.
12. Determine whether the issue is location-specific, device-specific,
    account-specific, destination-specific, or systemic.
13. Perform authorized corrective action.
14. Escalate to the appropriate network or voice-service team.
15. Record the final outcome.

Record:

- Ticket ID

- Outgoing-call status
- Call-drop frequency
- Audio-quality symptoms
- Reported location
- Indoor/outdoor status when relevant
- Movement status when relevant

- Device type
- SIM/eSIM status
- Network registration status

Do not record:

- Security answers
- Payment credentials

## Agent Guidance

Do not assume that poor call quality always means poor coverage.

Do not treat signal bars as a precise measurement of network quality.

Do not assume a single dropped call indicates a provider outage.

Do not expose internal network infrastructure or routing information.

Do not promise a specific restoration time without authoritative
provider information.

Do not create duplicate incidents when an existing voice-quality
incident already covers the same issue.

Provider-specific network-quality metrics, coverage information,
supported voice technologies, routing procedures, troubleshooting
procedures, incident information, and escalation policies should be
maintained separately as provider-specific policy documents.

## Scalability Requirements

For a large network provider, call-drop and voice-quality complaints
should support automated classification and correlation.

The architecture should support:

- Call-drop classification
- Audio-quality classification
- Location-based clustering
- Time-window analysis
- Network-cell correlation when available
- Complaint similarity analysis
- Device correlation
- SIM/eSIM correlation
- Roaming correlation
- Incident detection
- Duplicate incident prevention
- Related-ticket association
- Configurable thresholds
- Incident confidence scoring
- Human confirmation
- Network-team escalation
- Large numbers of simultaneous complaints

The system should allow large numbers of call-quality complaints to be
analyzed without requiring agents to manually compare every ticket.

## Example of Location-Specific Issue

Customer complaint:

"Calls keep dropping whenever I am inside my office, but they work
normally outside."

The system detects:

- Location-specific problem
- Indoor-only symptoms
- Calls work elsewhere

AI assessment:

POTENTIAL LOCAL COVERAGE OR BUILDING-PENETRATION ISSUE

Human action:

Review network coverage information and related complaints from the
same location before escalating as a broader incident.
