# DH-03: Device Calls and Connectivity

## Category

device_handset

## Subcategory

Device Calls and Connectivity

## Problem

The customer reports that calling, messaging, mobile data, Wi-Fi, Bluetooth, or other connectivity functions are not working correctly on their mobile device.

The issue appears to be related to device connectivity or configuration rather than a confirmed network outage.

## Example Customer Complaints

- "My phone cannot connect to mobile data."
- "My phone won't connect to Wi-Fi."
- "Bluetooth is not working on my phone."
- "My phone keeps losing its network connection."
- "Calls are not working on my phone."
- "My phone connects to Wi-Fi but the internet doesn't work."
- "My mobile data keeps disconnecting."
- "My phone cannot connect to any network."

## AI Assessment

POTENTIAL DEVICE CONNECTIVITY OR CONFIGURATION ISSUE

The complaint indicates a possible handset configuration, software, network-selection, or device connectivity problem.

## Recommended Human Action

Determine which connectivity function is affected:

- Voice calls.
- SMS.
- Mobile data.
- Wi-Fi.
- Bluetooth.
- Network registration.
- Multiple connectivity services.

Check:

- Device network settings.
- Airplane Mode.
- SIM/eSIM detection.
- Preferred network settings.
- Wi-Fi or Bluetooth status.
- Whether other devices can connect to the same network.
- Whether the problem occurs in multiple locations.
- Whether the issue began after a software or settings change.

## Basic Troubleshooting

For mobile connectivity:

1. Confirm Airplane Mode is disabled.
2. Restart the device.
3. Confirm the SIM/eSIM is enabled and detected.
4. Check the device's network settings.
5. Test the service in another location.
6. Check whether other mobile services work.

For Wi-Fi:

1. Confirm Wi-Fi is enabled.
2. Restart the device.
3. Forget and reconnect to the network using the normal device procedure.
4. Check whether another device can connect to the same Wi-Fi network.
5. Determine whether the problem affects one network or multiple networks.

For Bluetooth:

1. Confirm Bluetooth is enabled.
2. Restart Bluetooth.
3. Restart the device.
4. Verify that the other device is discoverable and compatible.
5. Remove and re-pair the device when appropriate.

## Diagnostic Interpretation

If only one device cannot connect while other devices work normally, investigate the handset or its configuration.

If multiple devices cannot connect to the same network, investigate the network or service instead.

If calls and mobile data are both unavailable, investigate SIM, mobile-line, coverage, or network conditions before assuming a handset fault.

If only one connectivity function is affected, use the most specific applicable category when sufficient information is available.

## Human Action

The support agent should:

1. Identify the affected connectivity service.
2. Determine whether the problem is device-specific.
3. Check relevant device settings.
4. Guide the customer through approved troubleshooting.
5. Check for known service issues where applicable.
6. Route the complaint to `mobile_service`, `internet`, `number_calling`, `sim_esim`, or `coverage_outage` when evidence indicates a different primary cause.

## Escalation

Escalate when:

- Connectivity fails after standard troubleshooting. 
- Multiple connectivity functions fail simultaneously without an identifiable service issue.
- The device requires authorized repair.
- A persistent software or configuration problem cannot be resolved remotely.

## Important Notes

Do not assume that every connectivity problem is caused by the handset.

Do not reset the device to factory settings unless the applicable support procedure specifically requires it and the customer understands the consequences.

Do not request or store passwords, authentication codes, or other sensitive credentials.

## Source Basis

This knowledge article is based on standardized telecom device-support workflows for diagnosing handset connectivity problems, distinguishing device-specific faults from network and service issues, troubleshooting mobile and wireless connectivity, routing complaints to the appropriate telecom category, and escalating persistent device-related problems.
