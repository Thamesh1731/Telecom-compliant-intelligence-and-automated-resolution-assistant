# DH-02: Device Setup and Configuration

## Category

device_handset

## Subcategory

Device Setup and Configuration

## Problem

The customer needs assistance setting up, configuring, or adjusting their mobile device.

The request may involve initial device setup, basic settings, transferring information, configuring supported features, or preparing the device for normal use.

## Example Customer Complaints

- "I need help setting up my new phone."
- "How do I configure my phone?"
- "I don't know how to set up my new device."
- "I need help transferring my data to my new phone."
- "How do I configure my mobile settings?"
- "My new phone isn't set up properly."
- "I need help with the phone settings."
- "How do I connect my new phone to my mobile service?"

## AI Assessment

MOBILE DEVICE SETUP OR CONFIGURATION REQUEST

The customer requires assistance configuring or preparing a mobile handset for normal use.

## Recommended Human Action

Determine what part of the setup is required:

- Initial device setup.
- Account configuration.
- Mobile network settings.
- Wi-Fi or Bluetooth setup.
- SIM/eSIM configuration.
- Data transfer.
- Application or system configuration.
- Device security settings.

## Basic Setup Guidance

Where applicable, ask the customer to:

1. Ensure the device has sufficient battery power.
2. Complete the manufacturer's initial setup process.
3. Connect the device to a reliable internet connection.
4. Sign in using the appropriate device account.
5. Install available system updates.
6. Configure the applicable mobile service.
7. Test calls, messaging, and mobile data after setup.

## Data Transfer

If the customer is transferring information from another device:

- Use the manufacturer's supported transfer method.
- Confirm that both devices are compatible with the transfer process.
- Ensure sufficient battery power.
- Maintain an appropriate connection during the transfer.
- Avoid deleting information from the old device until the transfer is confirmed.

## Human Action

The support agent should:

1. Identify the device model where relevant.
2. Determine the specific configuration problem.
3. Establish whether the issue is device-related or service-related.
4. Provide approved setup instructions.
5. Verify that the device functions normally after configuration.
6. Route the issue to a more specific category when appropriate.

## Routing

Route to `sim_esim` when the problem specifically concerns SIM or eSIM activation, detection, or replacement.

Route to `mobile_service` when the device is configured correctly but the mobile service itself is not working.

Route to `internet` when the issue specifically concerns mobile or fixed internet service.

## Escalation

Escalate when:

- The device cannot complete its initial setup.
- Configuration repeatedly fails.
- The device requires specialist support.
- The device shows a persistent system error.
- Data transfer cannot be completed through supported procedures.
- The issue appears to involve hardware or software failure.

## Important Notes

Do not provide instructions that bypass device security controls.

Do not request or store customer passwords, authentication codes, or other sensitive credentials.

Do not assume that a configuration problem is caused by the telecom network.

Do not recommend unofficial firmware modifications or unsupported software.

## Source Basis

This knowledge article is based on standardized telecom device-support workflows for assisting customers with mobile handset setup, configuration, data transfer, mobile service preparation, supported device settings, and escalation of setup problems requiring specialist intervention.
