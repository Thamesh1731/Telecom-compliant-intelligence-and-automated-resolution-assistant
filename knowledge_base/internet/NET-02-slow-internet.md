# NET-02: Slow Internet Speed

## Category
Internet / Network

## Problem
The customer reports that their internet connection is slower than expected.

## Common Symptoms
- Websites load slowly
- Video buffering
- Downloads take longer than expected
- Online applications respond slowly
- Internet speed is significantly lower than expected
- Slow performance occurs across multiple websites or applications

## Possible Causes
- Wi-Fi signal strength
- Distance from the router
- Multiple connected devices
- Heavy network usage
- Wireless interference
- VPN usage
- Router or gateway issues
- Network congestion
- Service outage or network-side problem
- Problem with a particular website or online service

## Troubleshooting Procedure

1. Determine whether the slowdown affects one website/application or multiple websites and applications.
2. Run an internet speed test using the provider's available diagnostic tool.
3. If testing over Wi-Fi, move closer to the router and repeat the test.
4. Disconnect devices that are not currently needed.
5. Stop high-bandwidth activities such as multiple video or audio streams.
6. If possible, perform the speed test using a wired Ethernet connection.
7. Disconnect any VPN connection temporarily and repeat the test when appropriate.
8. Check whether there is a known service outage or network issue.
9. Restart the router or gateway and test the connection again.
10. If the problem continues across multiple devices and test conditions, investigate the possibility of a network-side issue.

## Resolution

If the slowdown is caused by Wi-Fi distance, interference, device load, or other local conditions, provide the appropriate troubleshooting guidance.

If the measured connection remains significantly degraded after standard troubleshooting, the complaint should be investigated by technical support.

## Escalation Conditions

Escalate when:

- Slow performance persists after standard troubleshooting.
- The issue affects multiple devices.
- Wired testing also shows degraded performance.
- A service outage or network-side issue is suspected.
- The customer repeatedly reports unresolved slow-speed problems.

## Agent Guidance

Do not assume that every slow website indicates a telecom network problem.

First determine whether the issue is isolated to one website, one device, Wi-Fi connectivity, or the broader internet connection.
