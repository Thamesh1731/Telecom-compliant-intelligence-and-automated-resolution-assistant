# MOB-01: No Mobile Service

## Category
Mobile Service

## Subcategory
No Cellular Service

## Problem
The customer reports that their mobile device has no cellular service
or cannot connect to the mobile network.

## Common Symptoms
- "No Service" displayed on the device
- "Searching" displayed continuously
- "SOS" or "SOS Only" displayed
- No cellular signal
- Cannot make or receive calls
- Cellular data is unavailable
- Device cannot register on the mobile network
- Mobile service stopped working unexpectedly

## Possible Causes
- Temporary network connection problem
- Local cellular network outage
- Poor or unavailable network coverage
- Airplane Mode enabled
- SIM or eSIM problem
- Cellular line disabled
- Account or service problem
- Device blocked or barred from cellular service
- Incorrect carrier settings
- Outdated device software
- Device hardware problem
- Network-side problem

## Initial Diagnosis

Determine:

1. Whether the device displays "No Service", "Searching", or "SOS".
2. Whether the problem affects calls, SMS, mobile data, or all mobile
   services.
3. Whether the problem occurs in one location or multiple locations.
4. Whether other devices using the same network are affected, when
   information is available.
5. Whether the customer's account and mobile service are active.
6. Whether a network outage is affecting the customer's area.

## Troubleshooting Procedure

### 1. Check Airplane Mode

Verify that Airplane Mode is disabled.

If the device is already connected to the network but service is
unavailable, toggle Airplane Mode on and then off to attempt to
reconnect to the cellular network.

### 2. Restart the Device

Restart the mobile device.

After restarting, wait for the device to reconnect to the cellular
network and check whether service has returned.

### 3. Check Cellular Line

For devices using multiple SIMs or eSIMs:

- Verify that the intended cellular line is enabled.
- Verify that the correct line is selected for cellular service.
- Confirm that the SIM/eSIM is recognized by the device.

### 4. Check SIM or eSIM

If the device does not recognize the SIM:

- Verify that the physical SIM is inserted correctly.
- Check whether the SIM is damaged.
- If appropriate, test with another compatible SIM.
- For eSIM problems, verify that the carrier has correctly provisioned
  the eSIM.

Do not instruct the customer to remove or replace a SIM unless the
device and carrier procedure supports it.

### 5. Check Network Coverage

Determine whether the customer is currently in an area with cellular
coverage.

If possible, test the service from another location.

A temporary loss of coverage should not automatically be treated as a
device failure.

### 6. Check for Network Outage

Check whether the carrier reports a service outage affecting the
customer's area.

If a confirmed outage exists, avoid unnecessary device troubleshooting
and provide the available outage information.

### 7. Check Account Status

Verify through the carrier's support system that:

- The mobile account is active.
- The service plan is active.
- The device is not blocked or barred.
- There is no account-related restriction preventing service.

Account information must be verified through authorized carrier systems.

### 8. Check Device and Carrier Software

Where supported:

- Check for device software updates.
- Check for carrier/network settings updates.
- Install applicable updates.
- Restart the device and test service again.

## Diagnosis Guidance

### No Service in One Location

Possible causes:

- Poor coverage
- Local network issue
- Temporary outage
- Environmental interference

Test from another location when practical.

### No Service in Multiple Locations

Possible causes:

- SIM/eSIM problem
- Account problem
- Device configuration
- Device hardware
- Carrier/network problem

Further investigation is required.

### Multiple Customers Are Affected

If several customers using the same network and geographic area
experience loss of service, a provider-side outage or network problem
is more likely.

### Wi-Fi Works but Cellular Service Does Not

The device may still have Internet access through Wi-Fi.

Do not treat Wi-Fi connectivity as evidence that the cellular network
is working.

### Device Shows "SOS" or "SOS Only"

The device is not connected to its normal cellular provider's network.
Depending on device and region, emergency calls may still be possible
through another available network.

Normal cellular service troubleshooting should continue according to
the device and carrier procedures.

## Resolution

If service returns after reconnecting to the network or restarting the
device, confirm that calls, SMS, and mobile data are functioning as
expected.

If the issue is caused by a local coverage problem, explain the
available service limitations.

If a confirmed network outage exists, provide the available outage
information and avoid unnecessary troubleshooting.

If the account, network, and SIM/eSIM appear normal but the device still
cannot connect, escalate for further technical investigation.

## Escalation Conditions

Escalate when:

- No mobile service persists after standard troubleshooting.
- A network outage is suspected but cannot be confirmed automatically.
- The account is active but the device cannot connect.
- The SIM/eSIM appears damaged, invalid, or incorrectly provisioned.
- The device may be blocked or barred.
- Multiple customers in the same area appear to be affected.
- Device hardware failure is suspected.
- The issue repeatedly returns after temporary recovery.
- The problem requires carrier-side diagnostics or account changes.

## Agent Information to Record

Record:

- Ticket ID
- Customer location
- Device type, when available
- SIM/eSIM status
- Displayed network status
- Services affected
- Time the service stopped
- Whether Airplane Mode was toggled
- Whether the device was restarted
- Whether another location was tested
- Account/service status
- Known outage status
- Troubleshooting already completed
- Escalation reason

## Agent Guidance

Do not assume that "No Service" means the customer's device is
defective.

First distinguish between:

- Coverage problem
- Network outage
- Account problem
- SIM/eSIM problem
- Device configuration problem
- Device hardware problem

Do not promise restoration times unless an authoritative carrier
source provides one.

Do not request unnecessary sensitive account credentials in the
complaint record.
