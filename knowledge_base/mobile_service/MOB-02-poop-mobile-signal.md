# MOB-02: Poor Mobile Signal

## Category
Mobile Service

## Subcategory
Signal / Coverage

## Problem
The customer reports weak cellular signal, poor mobile coverage, or
unreliable mobile connectivity in a particular location or area.

## Common Symptoms
- Few or no cellular signal bars
- Calls have poor audio quality
- Calls disconnect or fail
- Mobile data is slow
- Mobile data repeatedly disconnects
- Service works outdoors but poorly indoors
- Service is weak in specific rooms or locations
- Signal quality changes significantly when the customer moves

## Possible Causes
- Weak cellular coverage in the customer's location
- Distance from a cellular network site
- Building walls or other physical obstructions
- Indoor signal attenuation
- Geographic terrain
- Network congestion
- Temporary network issue
- Local network outage
- Device or SIM/eSIM problem
- Cellular network compatibility or configuration issue

## Initial Diagnosis

Determine:

1. Current signal strength shown by the device.
2. Whether the problem occurs indoors, outdoors, or both.
3. Whether the problem occurs in one location or multiple locations.
4. Whether calls, SMS, mobile data, or all services are affected.
5. Whether another device using the same carrier experiences similar
   signal problems.
6. Whether the problem occurs at specific times or continuously.
7. Whether a known network outage exists in the area.

## Troubleshooting Procedure

### 1. Check Signal Strength

Check the cellular signal indicator on the device.

Record whether the device shows:

- Strong signal
- Moderate signal
- Weak signal
- No service

Signal indicators vary between devices and should be treated as a
general indication rather than an exact measurement.

### 2. Change Location

Move to a location with potentially better cellular coverage.

Where practical:

- Move closer to a window.
- Move outdoors.
- Move to a different area of the building.
- Test the service in another nearby location.

If the signal improves significantly after moving, the problem may be
related to local coverage or building conditions.

### 3. Check for Network Outage

Check the carrier's available service-status or outage information.

If a known outage affects the customer's area, avoid unnecessary
device troubleshooting.

### 4. Restart the Device

Restart the mobile device and allow it to reconnect to the cellular
network.

Test the signal again after restarting.

### 5. Check Airplane Mode

Verify that Airplane Mode is disabled.

If appropriate, toggle Airplane Mode on and off to force the device to
reconnect to the cellular network.

### 6. Check SIM/eSIM

If the device reports SIM-related errors or repeatedly loses cellular
service:

- Verify that the SIM is recognized.
- Check that the eSIM/cellular line is enabled.
- Verify carrier provisioning through the appropriate support system.

Do not assume that weak signal is caused by the SIM unless there is
supporting evidence.

### 7. Compare Locations

Determine whether the problem occurs:

- At one location only
- Across the local area
- Across multiple locations

A signal problem limited to one building or area is more likely to be
coverage-related than a device-wide problem.

### 8. Compare Devices

When practical, determine whether another device using the same carrier
experiences the same problem in the same location.

If multiple devices have similar signal problems, a coverage or
network-side issue is more likely.

## Diagnosis Guidance

### Poor signal only indoors

Possible causes:

- Building materials
- Distance from outdoor cellular infrastructure
- Indoor coverage limitations
- Local interference

Test outdoors or near a window when practical.

### Poor signal everywhere

Possible causes:

- Carrier coverage limitation
- SIM/eSIM problem
- Device configuration problem
- Device hardware problem
- Network-side problem

Further investigation may be required.

### Multiple customers affected in the same area

A carrier coverage or network-side problem is more likely.

The issue should be investigated using available network and
geographic information.

### Signal is strong but data is slow

Do not automatically classify this as a signal-strength problem.

Investigate:

- Network congestion
- Mobile data configuration
- Network availability
- Device-specific issues

### Signal is strong but calls are failing

Investigate call-service problems separately from signal strength.

## Resolution

If the issue is caused by location-specific coverage limitations,
provide available coverage guidance and practical options supported by
the provider.

If moving to another location restores service, explain that the
problem appears to be location-dependent.

If a confirmed network issue exists, provide the available service
status information.

If the problem persists across locations and standard troubleshooting
does not identify a cause, escalate for technical investigation.

## Escalation Conditions

Escalate when:

- Poor signal persists across multiple locations.
- Multiple customers appear to experience the same coverage problem.
- A network-side problem is suspected.
- The customer reports persistent signal problems despite adequate
  expected coverage.
- The device and account appear normal but cellular connectivity
  remains poor.
- The problem repeatedly affects calls, SMS, and mobile data.
- A carrier-side investigation is required.
- A potential coverage gap needs network evaluation.

## Agent Information to Record

Record:

- Ticket ID
- Customer city
- State
- ZIP code
- Approximate problem location, when available
- Signal strength indicated by device
- Services affected
- Indoor/outdoor condition
- Whether moving location changes the signal
- Whether another device was tested
- Whether an outage was identified
- SIM/eSIM status
- Troubleshooting completed
- Escalation reason

## Geographic Analysis

For network-scale analysis, customer location data such as city, state,
and ZIP code may be aggregated to identify concentrations of similar
signal complaints.

A geographic concentration of complaints may indicate a potential
coverage or network issue.

Location alone must not be treated as proof of a network problem.

The system should combine geographic information with:

- Complaint volume
- Complaint similarity
- Time of complaints
- Services affected
- Other available network information

before identifying a potential network issue.

## Agent Guidance

Do not assume that low signal bars automatically indicate a provider
fault.

First determine whether the problem is:

- Location-specific
- Device-specific
- Account/SIM-related
- Coverage-related
- Network-side

Do not promise that coverage will improve or that a network site will
be added unless an authorized provider source confirms it.
