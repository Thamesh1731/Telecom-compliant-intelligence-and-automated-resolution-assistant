# MOB-03: Dropped or Unstable Calls

## Category
Mobile Service

## Subcategory
Voice Calls

## Problem
The customer reports that voice calls frequently disconnect,
fail unexpectedly, or have unstable audio during a call.

## Common Symptoms

- Calls disconnect unexpectedly
- Calls drop in specific locations
- Calls drop repeatedly
- Incoming or outgoing calls fail intermittently
- Voice quality becomes poor during calls
- Audio cuts in and out
- The customer can make calls but cannot maintain a stable connection
- Calls work normally in some locations but not others

## Possible Causes

- Weak cellular signal
- Poor network coverage
- Temporary network problem
- Network congestion
- Local network outage
- Device software issue
- SIM/eSIM problem
- Device configuration problem
- Call forwarding or call-blocking configuration
- Account or service restriction
- Device hardware problem
- Wi-Fi Calling configuration or availability

## Initial Diagnosis

Determine:

1. Whether the problem affects incoming calls, outgoing calls, or both.
2. Whether calls drop at a specific location or everywhere.
3. Whether the problem occurs indoors, outdoors, or both.
4. Whether the device has a weak or fluctuating cellular signal.
5. Whether multiple calls are affected or only one call/number.
6. Whether other customers using the same carrier experience similar
   problems in the same area, when known.
7. Whether mobile data and SMS continue working normally.
8. Whether the problem started recently or has existed for a long time.

## Troubleshooting Procedure

### 1. Check Cellular Signal

Check the device's cellular signal.

If the signal is weak:

- Move to an area with better coverage.
- Move closer to a window when indoors.
- Test the call from another location.

If calls consistently improve in areas with stronger signal, the issue
may be coverage-related.

### 2. Restart the Device

Restart the mobile device.

After restarting, make another test call.

### 3. Check Airplane Mode

Verify that Airplane Mode is disabled.

If appropriate, toggle Airplane Mode on and off to reconnect the device
to the cellular network.

### 4. Check Device Software

Verify that the device is running supported and current software.

Install applicable updates and test calling again.

### 5. Check SIM/eSIM

If the device displays SIM-related errors or repeatedly loses cellular
connectivity:

- Verify that the SIM is recognized.
- Verify that the eSIM/cellular line is enabled.
- Check carrier provisioning through authorized support systems.

### 6. Check Call Settings

Check whether call-related settings could be interfering with service,
including:

- Call forwarding
- Call blocking
- Device call restrictions
- Relevant carrier calling features

### 7. Test Another Location

Make test calls from different locations.

Record whether calls:

- Work normally elsewhere
- Drop only in one location
- Drop across multiple locations

A location-specific problem may indicate a coverage or local network
issue.

### 8. Test Other Numbers

If possible, determine whether calls drop when contacting:

- One particular number
- Multiple numbers
- Different networks

If only calls to one number are affected, the issue may not originate
from the customer's mobile service.

### 9. Check for Network Problems

Check available carrier outage or service-status information.

If a network problem is confirmed, avoid unnecessary device
troubleshooting.

## Diagnosis Guidance

### Calls drop only in one location

Possible causes:

- Weak coverage
- Building obstruction
- Local network issue
- Coverage gap

Investigate location and signal conditions.

### Calls drop everywhere

Possible causes:

- Device problem
- SIM/eSIM issue
- Account/service issue
- Network-side problem
- Device software/configuration

Further investigation may be required.

### Calls drop but mobile data works normally

Possible causes:

- Voice-service configuration
- Network voice issue
- Call-specific settings
- Device software problem

Do not automatically classify this as a complete network outage.

### Calls and mobile data both fail

Consider:

- Weak/no coverage
- Network outage
- SIM/eSIM problem
- Account/service problem
- Device connectivity problem

### Only calls to one number fail

Investigate the possibility of:

- Number-specific issue
- Call blocking
- Destination network problem
- Incorrect number
- Inter-carrier call completion issue

Do not automatically attribute the problem to the customer's carrier.

## Resolution

If the problem is caused by weak coverage, provide appropriate
coverage-related guidance.

If restarting or reconnecting the device restores stable calling,
confirm the result with a test call.

If the issue is caused by a device setting, correct the setting when
possible.

If a confirmed network issue exists, provide the available service
information.

If calls continue to drop after standard troubleshooting, escalate for
technical investigation.

## Escalation Conditions

Escalate when:

- Calls repeatedly drop after standard troubleshooting.
- Calls drop across multiple locations.
- Multiple customers appear to experience similar problems in the same geographic area.
- A network-side issue is suspected.
- The account or service requires carrier-side investigation.
- Device hardware may be faulty.
- The issue repeatedly returns after temporary recovery.
- The problem cannot be resolved using available troubleshooting.

## Agent Information to Record

Record:

- Ticket ID
- Customer city
- State
- ZIP code
- Approximate problem location
- Incoming/outgoing call issue
- Call drop frequency
- Approximate duration before calls drop
- Signal condition
- Indoor/outdoor condition
- Whether another location was tested
- Whether other numbers were tested
- Whether mobile data works
- Whether SMS works
- SIM/eSIM status
- Device restart result
- Known outage status
- Troubleshooting completed
- Escalation reason

## Geographic Analysis

For network-scale analysis, aggregate similar dropped-call complaints by:

- City
- State
- ZIP code
- Time
- Complaint frequency

A concentration of dropped-call complaints in the same geographic area
may indicate a potential network or coverage problem.

Geographic concentration alone must not be treated as proof of a
network fault.

The system should combine geographic clustering with:

- Complaint similarity
- Number of affected customers
- Time patterns
- Signal-related information when available
- Other network information

before generating a network-level escalation.

## Agent Guidance

Do not automatically classify every dropped call as a network outage.

First determine whether the problem is:

- Location-specific
- Device-specific
- Number-specific
- SIM/eSIM-related
- Account-related
- Coverage-related
- Network-wide

Do not promise improved coverage, network upgrades, or a specific
resolution time unless an authorized provider source confirms it.
