# MOB-04: Mobile Data Problem

## Category
Mobile Service

## Subcategory
Mobile Data

## Problem
The customer reports that cellular/mobile data is unavailable, slow,
unstable, or performing below expectations while connected to the
mobile network.

## Common Symptoms

- Mobile data does not work
- Websites do not load over cellular data
- Apps cannot access the Internet without Wi-Fi
- Mobile data is significantly slower than expected
- Downloads or uploads are slow
- Mobile data repeatedly disconnects
- Mobile data works intermittently
- Mobile data works in some locations but not others
- Mobile data works but at reduced speeds
- Cellular signal appears available but Internet access does not work

## Possible Causes

- Mobile data is disabled
- Weak or inconsistent cellular signal
- Network congestion
- Network outage or temporary network problem
- Customer has reached a plan-specific high-speed data limit
- Data usage restriction or speed-management feature
- Device network configuration problem
- SIM/eSIM problem
- Account or service restriction
- Device software problem
- Carrier network problem
- Application-specific problem

## Initial Diagnosis

Determine:

1. Whether mobile data is enabled.
2. Whether the device shows a cellular network connection.
3. Whether calls and SMS work normally.
4. Whether the problem affects all applications or only one application.
5. Whether the problem occurs in one location or multiple locations.
6. Whether the customer's data allowance or applicable high-speed
   threshold has been reached.
7. Whether other devices using the same carrier experience similar
   problems in the same area, when known.
8. Whether a network outage is currently reported.

## Troubleshooting Procedure

### 1. Check Mobile Data

Verify that cellular/mobile data is enabled on the device.

If mobile data is disabled, enable it and test the connection again.

Wi-Fi and mobile data are separate connections. A device connected to
Wi-Fi may access the Internet even when cellular data is unavailable.

### 2. Check Cellular Signal

Check the device's cellular signal indicator.

If the signal is weak:

- Move to an area with stronger coverage.
- Move near a window or outdoors when practical.
- Test the connection from another location.

Weak or inconsistent cellular signal can result in slow or unstable
mobile data.

### 3. Test Multiple Services

If a particular application cannot connect:

- Try another website.
- Try another application that requires Internet access.
- Test a browser.
- Determine whether the problem affects all Internet services.

If only one application is affected, do not immediately classify the
problem as a mobile-network failure.

### 4. Toggle Airplane Mode

Verify that Airplane Mode is disabled.

When appropriate, toggle Airplane Mode on and off to reconnect the
device to the cellular network.

### 5. Restart the Device

Restart the mobile device.

After restarting, allow it to reconnect to the cellular network and
test mobile data again.

### 6. Check Data Usage

Check the customer's available data usage and applicable plan limits.

Determine whether:

- The customer's high-speed data allowance has been reached.
- A plan-specific speed-management feature applies.
- A data restriction is active.

Plan-specific rules vary between providers and plans.

### 7. Check Network Conditions

Determine whether the problem could be caused by:

- Network congestion
- Temporary network disruption
- Local network outage
- High traffic in the customer's area

Network congestion can vary by location and time.

### 8. Check SIM/eSIM

If the device repeatedly loses cellular data connectivity:

- Verify that the SIM/eSIM is recognized.
- Verify that the correct cellular line is enabled.
- Check carrier provisioning through authorized support systems.

### 9. Check Device Software and Network Configuration

Where supported:

- Check for software updates.
- Check for carrier/network settings updates.
- Review cellular network settings.
- Restart the device after applicable updates.

Network settings should only be reset when appropriate because resetting
them can remove saved network configurations.

## Diagnosis Guidance

### Mobile data does not work but calls and SMS work

Possible causes:

- Mobile data disabled
- Data configuration problem
- Data allowance or plan restriction
- SIM/eSIM provisioning issue
- Network-side data problem
- Device configuration problem

### Mobile data and calls both fail

Consider:

- Weak/no coverage
- Network outage
- SIM/eSIM problem
- Account/service problem
- Device connectivity problem

Refer to the appropriate mobile-service troubleshooting workflow.

### Mobile data works slowly but signal is strong

Possible causes:

- Network congestion
- Plan-specific speed restriction
- High data usage
- Temporary network problem
- Device or application issue

Do not automatically classify strong-signal slow data as a coverage
problem.

### Mobile data works in one location but not another

Possible causes:

- Coverage difference
- Local network congestion
- Local network issue
- Geographic/environmental conditions

### Only one application cannot access mobile data

The problem may be application-specific or related to the device's
application settings.

Test other Internet services before escalating the mobile network.

## Speed Testing

When supported by the provider or device:

1. Disconnect from Wi-Fi.
2. Confirm that the device is connected to the cellular network.
3. Run an available mobile-data speed test.
4. Record the approximate result.
5. Repeat from another location if necessary.

A speed test should be interpreted together with signal conditions,
network congestion, plan limitations, and test location.

## Resolution

If mobile data was disabled, enable it and verify connectivity.

If weak signal is responsible, provide appropriate coverage-related
guidance.

If a data limit or plan-specific restriction is responsible, explain the
applicable plan condition.

If temporary network congestion or an outage is identified, provide the
available network-status information.

If the problem persists after standard troubleshooting, escalate for
technical investigation.

## Escalation Conditions

Escalate when:

- Mobile data remains unavailable after standard troubleshooting.
- Mobile data remains consistently slow despite adequate signal and
  normal plan conditions.
- Multiple customers appear to experience similar problems in the same
  geographic area.
- A network-side problem is suspected.
- The account or data service requires carrier-side investigation.
- SIM/eSIM provisioning appears incorrect.
- The problem repeatedly returns after temporary recovery.
- The issue cannot be resolved using available troubleshooting.

## Geographic Analysis

Mobile-data complaints can be aggregated using:

- City
- State
- ZIP code
- Date
- Time
- Complaint similarity

A high concentration of similar mobile-data complaints within a
geographic area and time period may indicate a potential network
problem.

Location and complaint volume alone must not be treated as proof of a
network fault.

Potential network-level escalation should consider:

- Number of similar complaints
- Geographic concentration
- Time concentration
- Services affected
- Signal information when available
- Known network events

## Agent Guidance

Do not assume that slow mobile data is caused by weak signal.

Consider:

- Signal strength
- Network congestion
- Data-plan conditions
- Data usage
- Device configuration
- Application-specific issues
- Network outages

Do not promise a specific data speed or restoration time unless an
authorized provider source confirms it.

Do not hard-code provider-specific data thresholds into this generic
knowledge article. Those values belong in provider-specific policy
documents.
