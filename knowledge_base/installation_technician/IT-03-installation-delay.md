# IT-03: Installation Delay and Scheduling Problems

## Category

installation_technician

## Subcategory

Installation Delay and Scheduling Problems

## Problem

The customer reports that a requested installation or technician appointment has been delayed, postponed, missed, or has not progressed as expected.

The issue may involve a delayed installation order, a missed appointment, an unresolved scheduling issue, or a technician visit that has not occurred within the expected process.

## Example Customer Complaints

- "My installation is delayed."
- "My technician appointment was postponed."
- "Nobody came for my installation."
- "My installation date has passed but the service is still not installed."
- "The technician never arrived."
- "Why has my installation been delayed?"
- "My installation order has not been completed."
- "I have been waiting for installation for several days."

## AI Assessment

## Recommended Human Action

Check:

- Installation order status.
- Original requested date.
- Scheduled appointment.
- Technician assignment.
- Appointment status.
- Previous technician notes.
- Rescheduling history.
- Service availability at the installation location.
- Any known infrastructure or operational delays.

## Human Action

The support agent should:

1. Verify the customer's account and installation order.
2. Confirm the service address.
3. Review the current installation status.
4. Check whether an appointment was scheduled.
5. Determine the reason for the delay where available.
6. Reschedule the technician visit if appropriate.
7. Escalate when the delay cannot be resolved through normal scheduling procedures.
8. Record the updated status and applicable reference number.

## Missed Technician Visit

If the customer reports that the technician did not arrive:

- Verify the appointment status.
- Check available technician notes.
- Determine whether the visit was cancelled or rescheduled.
- Arrange a new appointment when required.
- Escalate repeated missed appointments.

## Delayed Installation Order

If the installation order has remained pending:

- Check whether additional information is required.
- Verify service availability.
- Check for infrastructure limitations.
- Determine whether a site assessment is required.
- Escalate to the appropriate installation or technical team when necessary.

## Escalation

Escalate when:

- The scheduled installation date has passed without completion.
- The technician repeatedly fails to attend.
- The installation has been delayed multiple times.
- The order is stuck without a clear reason.
- Infrastructure work is required.
- A site assessment is required.
- The customer has experienced prolonged unresolved delay.

## Important Notes

Do not invent a reason for an installation delay.

Do not promise a new installation date without confirmed scheduling availability.

Do not guarantee compensation, refunds, or priority handling unless authorized policy and account information confirm it.

## Source Basis

This knowledge article is based on standardized telecom installation-support workflows for investigating delayed installation orders, missed technician appointments, scheduling failures, infrastructure dependencies, rescheduling, and escalation of prolonged installation delays.
